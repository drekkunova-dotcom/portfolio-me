# Подборки — обычный флоу

Убраны отдельная плашка «Мансардное окно», вынесенная фотография и её перелёты. После сохранения открывается штатное подтверждение с готовым содержимым, затем — подборка. Миниатюры остаются частью экранов приложения.

Сохранены зелёный градиент первого заголовка, белые полупрозрачные тапы, музыка и исходный интерфейс. Финальный телефон расположен по центру, без дополнительного увеличения. Убраны паузы прежних перелётов; длительность — 19 секунд.

Формат: 1920 × 1080, 30 fps, H.264 + AAC. ZIP содержит готовый MP4.

Проверка: отсутствие отдельных плашек и перелётов; попадание тапов в цели; содержимое панелей при открытии; положение финального телефона; декодирование всего файла; контактные листы готового MP4; отсутствие пустых кадров и клиппинга; целостность ZIP. После публикации оба файла скачиваются по прямым ссылкам и сверяются по SHA256.
