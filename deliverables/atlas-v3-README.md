# ATLAS — Севан и Ереван

15 секунд, 3840 × 2160, 30 fps. Порядок исходных экранов 01 → 02 → 03 → 04 → 05 → 06 → 07 сохранён; в карту добавлен выбор Севана перед выбором Еревана.

Севан раскрывается в плотный коллаж с семью отдельными изображениями, белыми обводками и синей меткой «севан». Затем этот набор сворачивается обратно, а по нажатию на Ереван открываются исходные находки Еревана. Для Севана по просьбе пользователя созданы новые референсные изображения озера, церкви, хачкара, лодки, керамики, каменного орнамента и берега. Это созданные изображения для демонстрации, а не фотографии пользователя.

Карта очищена от прямоугольных подложек, дорожные линии обработаны по исходным контурам для уменьшения ступенек и улучшения контраста. Позиции городов и исходные числа сохранены. Мелкая детализация ограничена встроенным растром исходных PNG; новых картографических данных не добавлено. При переходе старые маркеры не оставляют пустых заплаток.

Камера неподвижна. Сохранены новая лёгкая мелодия 112 BPM и синхронные звуки нажатий. Последний кадр — исходная карточка «девушка с голубями».
