# ATLAS — версия 7

15 секунд, 3840 × 2160, 30 fps. MP4: H.264 + AAC, начало воспроизведения без загрузки всего файла. ZIP содержит готовый 4K MP4.

Севан раскрывается в коллаж из семи фотографий. Синяя плашка «севан» перенесена вниз к стыку нижних двух фотографий по стрелке пользователя. Семь фотографий Севана собраны плотным асимметричным коллажем по образцу Еревана.

После нажатия на Ереван коллаж раскрывается прямо на общей карте. Одновременно справа выезжает исходная панель с шестью альбомами, уже заполненная содержимым. Прежний крупный план маркера Еревана убран. Затем сохранён флоу: альбом → объекты → подробная карточка «девушка с голубями».

Перед выбором категории «Искусство и скульптура» камера плавно приближается на 32%; после тапа возвращается к общему виду. На остальных участках камера неподвижна. Сохранены одобренная мелодия 112 BPM, полупрозрачные белые тапы и синхронные интерфейсные звуки. Кадр с результатом остаётся читаемым до конца, без затемнения.

Изображения Севана созданы по просьбе пользователя для демонстрации. Это не пользовательские документальные фотографии. География и исходные числа сохранены. Мелкая детализация карты ограничена встроенным растром исходных PNG; новых картографических данных не добавлено.

Проверены контакт-листы и переходы готового MP4, разрешение, частота, 450 кадров, длительность, полное декодирование, отсутствие пустых кадров, звук без клиппинга, целостность ZIP.

Фон списка артефактов восстановлен по исходному экрану 06: сплошной светло-серый #F4F4F4 между белыми карточками со скруглениями. На остановке показывается исходный фрагмент PNG целиком, без сборных швов.

Обновление 26 ноября: применены animate, choreograph и review-animations из установленного набора Emil Kowalski с учётом формата продуктового ролика Dodo. Список объектов входит одной согласованной панелью; убраны четыре пересекающиеся траектории карточек. У выбранного объекта восстановлен заметный press-feedback. Фотография наследует текущее положение и масштаб при переходе в подробную карточку; уход остальных элементов синхронный, подписи двух состояний не накладываются. Звуки появления приведены к одной общей смене панели.
