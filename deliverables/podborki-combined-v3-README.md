# Подборки — объединённый ролик v3

Исправлен скачок размера телефона между частями. Начало Collections увеличено на 16% вокруг центра кадра до размера телефона в предыдущей сцене. Эта поправка плавно снимается одновременно с существующим приближением камеры, поэтому отдельного уменьшения нет. Для чёткости использован исходный мастер Collections 4K.

Сохранены монтаж v2, все действия, короткий стык и непрерывная музыкальная дорожка с тапами. Звук побитово совпадает с декодированным звуком v2. Длительность 30,4 с, 1920 × 1080, 30 fps. Проверены габариты телефона на стыке, кадры движения, полное декодирование и ZIP.
