# Персональный моушен-набор

Универсальная версия скилла Dodo для мобильных фич: Onest, персональная зелёная палитра и светлый фон. Конкретные экраны, тексты, порядок действий и длительность задаются заново для каждого ролика.

Начни с SKILL.md. BRAND.md и brand.tokens.json содержат тему. references/scenario.md описывает общий процесс согласования. В kit/ находятся инструменты анимации, рендера и звука, а также локальный шрифт с лицензией.

GSAP, Playwright и FFmpeg нужны отдельно. Исходники конкретного интерфейса и готовое видео в набор не включены.
