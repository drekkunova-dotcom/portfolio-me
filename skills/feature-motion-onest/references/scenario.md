# Сценарий и согласование

Для каждого ролика создай новый план по актуальным материалам пользователя.

1. Уточни только недостающее: цель, ключевое действие, исходники и ограничения.
2. Проверь смысловой порядок экранов по флоу пользователя.
3. Выбери состояния: контекст, действие, отклик, результат. Не все задачи требуют отдельной сцены для каждого состояния.
4. Для каждого перехода укажи сохраняющийся элемент и объясни движение внимания.
5. Подготовь визуальную сетку: время, композиция, действие, переход и звук. Тайминги зависят от читаемости текущего материала.
6. Согласуй сетку до нового монтажа. После согласования собери превью и проверь переходы покадрово.
7. Внеси правки, проверь экспорт и передай готовый результат.

Номера, названия файлов и временные метки из других проектов не задают порядок нового ролика. Постоянный сценарий в этот набор не встроен.
